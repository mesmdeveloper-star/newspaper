# Saurabh's AI Daily — Generation Rules

## Daily Developer Corner

Every daily edition MUST include a **Developer Corner**.

For each edition:
1. Search the web for developer-relevant AI releases and announcements from the **previous 7 days**.
2. Prefer primary sources: official release notes, GitHub releases, vendor engineering blogs, SDK/changelog pages, and official documentation.
3. Prioritize:
   - AI SDKs and APIs
   - coding agents and CLIs
   - agent frameworks and orchestration
   - MCP and tool integrations
   - inference/serving stacks
   - open-weight/local AI tooling
   - databases, vector stores and memory systems
   - observability/evaluation
   - sandboxes, deployment and cloud infrastructure
   - multimodal/voice developer tooling
4. Include 3–6 items that are genuinely new or materially changed during the week.
5. Each item must contain: category, release/development title, date when available, a concise practical developer impact, and a source link.
6. Do not recycle an older item merely because it is popular; prefer something shipped or materially updated this week.
7. Refresh this section every day even when the rest of the newspaper is dominated by model/company news.
8. Keep the section factual and avoid ranking tools as “best” or “worst.”

## Visuals

Do NOT generate or include a standalone **“🖼️ Images From Today's AI Coverage”** section. Images may still appear inside individual news cards when they materially improve the story.
