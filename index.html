DEVELOPER CORNER • SEPTEMBER 30

👨‍💻 What builders should act on

Practical engineering
AGENT ARCHITECTURE

Design for long-running state

Dots and Codex Cloud make persistent work a first-class workflow. Persist task state, checkpoints, tool results and approvals instead of assuming one request equals one run.

SECURITY

Put policy at the tool boundary

Use sandboxed execution, least-privilege credentials, allowlisted network access, approval gates and immutable traces. Never rely on the system prompt as the only control.

MODEL ROUTING

Route by task, not brand

Compare models on your own coding, retrieval, vision, tool-calling, latency and cost suites. Sonnet 5.5's efficiency claims are useful signals, but your workload should decide routing.

CODING

Test agentic coding end-to-end

Measure successful PRs, regression rate, number of tool calls, token spend, wall-clock time and human intervention. Leaderboard scores alone miss workflow overhead.

MCP

Treat MCP servers as production services

Version them, isolate credentials, validate inputs, rate-limit calls and log every invocation. A compromised tool server can bypass model-level safety assumptions.

VOICE AI

Benchmark latency and interruption handling

For voice agents, evaluate time-to-first-audio, barge-in recovery, pronunciation, turn-taking and failure recovery—not only TTS naturalness.
