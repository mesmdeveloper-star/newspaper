MCP infrastructure needs production-grade isolation

Open-source MCP security projects are becoming more important as tool servers move into production. Run them in containers, keep credentials scoped and log all tool invocations.

Maintain tests for tool calling, computer use, visual inputs, long-context retrieval, refusal behavior and cost/latency. A new model can change application behavior even when your code is unchanged.
